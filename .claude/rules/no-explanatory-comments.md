# Commentaires

Exprimer l'intention par les noms métier, les fonctions courtes et la structure du code. Ne pas ajouter spontanément de commentaires explicatifs, JSDoc, docstrings, TODO, bandeaux ou code commenté. Renommer, extraire ou simplifier lorsque cela rend le code compréhensible.

Les commentaires explicitement demandés sont autorisés. Conserver les commentaires générés, les licences et les très courtes explications d'une contrainte externe que le code ne peut pas exprimer.
